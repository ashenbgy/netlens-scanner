# Alpha NetScope Privacy Policy

Last updated: 17 September 2026

## Data processed

Alpha NetScope reads Wi-Fi network names, BSSIDs, channels, and signal levels from the device to show live signal strength and nearby networks. These readings are kept in memory only while the app is open.

## Permissions

Wi-Fi access supports connected-signal monitoring. Android may require Location permission and Location services for nearby access-point scans. No other permissions are requested.

## Storage and retention

Only the onboarding preference and diagnostic logs are stored locally in the app's device storage. They remain until the user clears diagnostics, clears app data, or uninstalls the app.

## Sharing

Alpha NetScope does not automatically upload analytics or crash reports. Diagnostic reports leave the app only when the user invokes the share action and chooses a destination.

## Crash diagnostics

Uncaught error details and stack traces are saved locally for troubleshooting. The user can inspect, share, or delete these reports from **Privacy & support → Diagnostics**. Reports can contain technical file paths but are designed not to include Wi-Fi contents.

## User control

Users can deny Location permission and still monitor the connected signal, clear diagnostic reports, and delete all application data through device settings.
